# Changelog

All notable changes to Smart KPI Flip Card are documented here.

## 1.0.0 — 2026-08-05

- Completed the Smart KPI front/back experience with Label, Card Value, Detail Value, Comparison Value, Target Value, and repeatable Tooltips roles.
- Added tested target/comparison status priority, higher/lower direction, tolerance, variance modes, zero-reference safety, and conditional colors.
- Added the modern six-card Format pane model and Power BI-aware number formatting.
- Separated selection from flipping; added multi-select, selection restoration, blank-space clear, context menus, and native tooltips.
- Added responsive compact/tiny layouts, keyboard and screen-reader support, high contrast, and reduced motion.
- Added rendering-event lifecycle handling, polished data states, strict modular TypeScript, meaningful tests, and CI.
- Removed tracked dependencies and generated content, pinned a reproducible Node 24 toolchain, repaired metadata, and added production packaging.
